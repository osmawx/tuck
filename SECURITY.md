# Security policy

Security fixes target the current `main` branch and the latest published Tuck release. Install the latest release when available.

## Report a vulnerability privately

Use [Report a vulnerability](https://github.com/osmawx/tuck/security/advisories/new) to open a private report. Please keep vulnerability details in that report until maintainers coordinate disclosure with you.

Include the Tuck build, macOS version, affected behavior, and steps to reproduce it. Sanitize logs and screenshots before attaching them. Please use GitHub Issues for general bugs and feature requests.
